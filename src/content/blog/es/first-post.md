# Bienvenido al futuro del desarrollo web

Este es tu primer artículo renderizado con tu flamante **plantilla base de Astro**.

Como conectamos el cargador nativo `glob` y la utilidad `render`, aquí puedes escribir Markdown o MDX estándar, y Astro lo convertirá automáticamente en HTML limpio.

## Por qué esta configuración es fantástica:
- **Optimización automática:** la imagen destacada que se especifica en el frontmatter queda registrada por Astro.
- **SEO estricto:** si borras la línea de la descripción de arriba, el servidor lanza un error al instante, evitando que una página rota llegue a producción.
- **Listo para Tailwind:** cualquier clase que uses aquí se compila automáticamente.
